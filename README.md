# 📋 Task Manager

A beautiful, fully-functional task management application built with vanilla JavaScript, HTML, and CSS.

## 🎯 Features

✅ **Add Tasks** - Quickly add new tasks with categories
✅ **Organize by Category** - Work, Personal, Shopping, Health, Other
✅ **Check Off Completion** - Mark tasks as done with a single click
✅ **Delete Tasks** - Remove tasks you no longer need
✅ **Filter Tasks** - View All, Active, or Completed tasks
✅ **Progress Tracking** - See statistics for total, active, and completed tasks
✅ **Auto-Save** - Tasks are automatically saved to browser storage
✅ **Beautiful UI** - Gradient design with smooth animations
✅ **Mobile Responsive** - Works perfectly on all devices
✅ **Enter to Add** - Quick task creation with keyboard shortcut

## 🚀 How to Use

1. **Open** `index.html` in your web browser
2. **Type** your task in the input field
3. **Select** a category from the dropdown
4. **Click** "Add" or press Enter
5. **Check off** tasks as you complete them
6. **Delete** tasks when no longer needed
7. **Filter** to view specific task types

## 📦 Files Included

- **index.html** - Application structure
- **styles.css** - Beautiful styling and animations
- **script.js** - All functionality (vanilla JS, no dependencies)

## 💾 Data Storage

All tasks are saved to your browser's local storage automatically. Your tasks will persist even after closing the browser.

## 🎨 Features Breakdown

### Categories
- **Work** - Professional and work-related tasks
- **Personal** - Personal errands and goals
- **Shopping** - Shopping list items
- **Health** - Health and fitness tasks
- **Other** - Miscellaneous tasks

### Filters
- **All** - See every task
- **Active** - Only incomplete tasks
- **Completed** - Only finished tasks
- **Clear Completed** - Delete all completed tasks at once

### Statistics
Real-time display of:
- Total number of tasks
- Number of completed tasks
- Number of active tasks

## 🔧 Technical Details

- **Pure JavaScript** - No dependencies or frameworks
- **Local Storage API** - Persistent data without server
- **Responsive CSS** - Adapts to all screen sizes
- **ES6 Class-based** - Clean, organized code structure
- **XSS Protection** - HTML escaping for security
